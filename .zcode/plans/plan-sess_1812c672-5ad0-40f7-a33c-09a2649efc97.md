# 公开只读 Live Demo（保留编辑入口、保存时弹 Demo 提示）

## Context

仓库已开源，希望 `https://radar.chandler.work/products/reporadar` 成为人人可见的 live demo。已确认：仓库无 middleware，页面各自调 `requireSessionUser`；`getProductDetails(slug)` 是纯读、支持无组织过滤；编辑表单（feature/scenario/概况）数据均由服务端组件以 props 传入，打开编辑器不发网络请求；所有保存/删除/分析统一从客户端组件调用 `lib/spec-editor-client.ts` 与 `lib/product-client.ts` 的 fetch 函数；写 API 全部自带 session + editor 角色校验。

**按你的要求：编辑入口全部保留可点、表单可打开可填写，但点保存时弹「Demo 模式不可保存」提示，不发请求。**

## 方案：slug 白名单 + 匿名时 Demo 模式

- 环境变量 `PUBLIC_DEMO_SLUGS`（逗号分隔，默认空 = 功能关闭，现有行为零变化）
- `app/products/[slug]/page.tsx` 分支逻辑：
  - **已登录**（`getSessionUser()` 非 null）：走现有 `requireProductAccess` 完整流程，你自己的编辑体验完全不变
  - **匿名 + slug 在白名单**：Demo 模式渲染——不调 requireSessionUser/requireProductAccess，用 `getProductDetails(slug)`（null → notFound）
  - **匿名 + slug 不在白名单**：维持现状（跳登录）
  - （已登录但无权限访问白名单 slug 的用户也回落到 Demo 模式，避免 404）

## 实现步骤

1. **`lib/env.ts`**：新增 `publicDemoSlugs()` 解析 `PUBLIC_DEMO_SLUGS`。
2. **新组件 `components/demo-mode.tsx`**（"use client"）：`DemoModeProvider`（context）+ `useDemoMode()` hook + 一个 `<dialog>` 提示框（「Demo 模式：这是只读演示站点，编辑内容不可保存」+ 确定按钮）。
3. **保存拦截**（在各客户端组件的保存函数入口加 `useDemoMode()` 判断，命中则 `showNotice()` 并 return，不发请求）：
   - `components/edit-description-button.tsx` → `save()`
   - `components/analyze-button.tsx` → `analyze()`（分析会消耗 AI 费用，Demo 中同样弹提示）
   - `components/feature-form.tsx` / `components/scenario-form.tsx` → 保存处理函数
4. **隐藏两处**（匿名 Demo 下无意义且需登录）：`RemoveProductButton`、`AnalysisFeedbackButton`（页面已有 `access.role !== "viewer"` 条件，Demo 分支不传即可）。
5. **页面外壳**：匿名时用精简公共外壳（站点名 + 「使用 Chandler 登录」链接 + GitHub 仓库链接）替代 `AppShell`（其侧边栏均指向需登录页面）；`ProductTabs`/`ProductView` 等服务端组件原样复用，编辑按钮照常渲染（被第 3 步拦截）。
6. **`.env.example` + README**：补 `PUBLIC_DEMO_SLUGS` 说明。
7. **测试**（vitest，沿用 `tests/dashboard-page.test.ts` 的 `renderToStaticMarkup` + mock 模式）：
   - 匿名访问白名单 slug：渲染成功、编辑按钮存在（如「✎」「＋ 新功能」）、无「删除产品」
   - 匿名访问非白名单 slug：跳登录不渲染（可断言 redirect）
   - `publicDemoSlugs()` 解析测试
   - Demo 模式下点击保存不触发 fetch（mock `lib/spec-editor-client` 断言未调用）——视组件测试可行性，至少覆盖 env 与页面两个层级
8. **验证**：`npm run typecheck && npm test && npm run build` → push（自动触发 webhook 分析）→ 服务器 `git pull + npm run build + restart` → 生产 `.env` 加 `PUBLIC_DEMO_SLUGS=reporadar` → 无痕窗口访问 `/products/reporadar`：各 Tab 可浏览、编辑器可打开、保存弹 Demo 提示、网络面板无写请求发出。

## 安全边界

- 白名单默认空：不开配置零行为变化
- 所有写 API 不改动，匿名者绕过前端伪造请求会被 session/角色校验拒绝
- 仅白名单产品的只读数据（specs/releases/changes）对外可见，不泄露其他产品与用户信息
